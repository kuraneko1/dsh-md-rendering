# dsh-md-rendering

DSH のチャット内の Markdown 表に、Project Hub の PWA を参考にした文字サイズ、フォント、余白、罫線、背景、横スクロールを適用する独立プラグインです。Markdown の解析や表以外の本文、チャット以外のプレビューは変更しません。Project Hub と同様、Markdown で指定した列の揃え方にかかわらず左揃えで表示します。

横スクロールには DSH の既存の表ラッパーを使うため、Project Hub の表本体をスクロールする実装とは異なります。色は DSH のテーマに合わせます。

DSH のプラグイン管理からこのディレクトリをバンドルとしてインストールできます。無効化または削除すると標準の表示に戻ります。画面への反映には再読み込みが必要な場合があります。

DSH の表・チャットの DOM 構造に依存するため、DSH の更新後は表示を確認してください。
